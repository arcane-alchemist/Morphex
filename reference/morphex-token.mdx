`MorphexToken` is a confidential fungible token built on OpenZeppelin ERC-7984 and Zama fhEVM. Balances, transfers, mints, and burns are encrypted end to end. The contract also exposes a relayer bridge so a public ERC-20 can be wrapped into a confidential token and later unwrapped through `RelayerVault`.

## Overview

```solidity
import {FHE, euint64, externalEuint64} from "@fhevm/solidity/lib/FHE.sol";
import {ZamaEthereumConfig} from "@fhevm/solidity/config/ZamaConfig.sol";
import {ERC7984} from "@openzeppelin/confidential-contracts/token/ERC7984/ERC7984.sol";
import {AccessControl} from "@openzeppelin/contracts/access/AccessControl.sol";
import {Ownable} from "@openzeppelin/contracts/access/Ownable.sol";

contract MorphexToken is ERC7984, ZamaEthereumConfig, Ownable, AccessControl { ... }
```

Inherits `ERC7984` (confidential balances via encrypted handles), `ZamaEthereumConfig` (fhEVM wiring), `Ownable` (owner-only administration), and `AccessControl` (role-gated relayer functions).

The contract also declares an internal `IRelayerVault` interface used only to call the vault:

```solidity
interface IRelayerVault {
    function registerWithdrawalRequest(address user, address token, uint256 amount) external returns (uint256 requestId);
    function registerWithdrawalRequestTo(address user, address recipient, address token, uint256 amount) external returns (uint256 requestId);
}
```

## Constructor

```solidity
constructor(
    string memory tokenName,
    string memory tokenSymbol,
    address initialOwner
) ERC7984(tokenName, tokenSymbol, "") Ownable(initialOwner)
```

<ParamField path="tokenName" type="string">
  Human-readable token name (for example, `"Confidential Tether"`).
</ParamField>

<ParamField path="tokenSymbol" type="string">
  Ticker symbol (for example, `"cUSDT"`).
</ParamField>

<ParamField path="initialOwner" type="address">
  Address that receives `DEFAULT_ADMIN_ROLE`, `RELAYER_ROLE`, and Ownable ownership at deploy time.
</ParamField>

The constructor grants `DEFAULT_ADMIN_ROLE` and `RELAYER_ROLE` to `initialOwner`, and sets `relayer = initialOwner`. The third `ERC7984` constructor argument (base URI) is passed as an empty string.

## Access control

| Surface | Guard |
| --- | --- |
| `setRelayerVault`, `setUnderlyingToken`, `setRelayer`, `mint` | `onlyOwner` |
| `relayerMint` | `onlyRole(RELAYER_ROLE)` |
| `relayerBurnRequest`, `relayerBurnRequestTo` | Callable by any token holder |

```solidity
bytes32 public constant RELAYER_ROLE = keccak256("RELAYER_ROLE");
```

`RELAYER_ROLE` is rotated by the owner via `setRelayer`, which revokes the previous holder before granting the new one.

## State

```solidity
address public relayerVault;
address public underlyingToken;
address public relayer;
```

- `relayerVault`: `RelayerVault` address that records public withdrawal requests.
- `underlyingToken`: Public ERC-20 that backs this confidential token (for example, USDT).
- `relayer`: Current holder of `RELAYER_ROLE`.

## Administration

### setRelayerVault

```solidity
/// @notice Sets the vault that records public withdrawal requests for this confidential token.
function setRelayerVault(address vault) external onlyOwner;
```

Sets the vault used by `relayerBurnRequest` and `relayerBurnRequestTo`. Reverts on the zero address (`"Morphex: zero vault"`). Emits `RelayerVaultUpdated`.

### setUnderlyingToken

```solidity
/// @notice Sets the public stablecoin backing this confidential token (e.g. USDT/USDC).
function setUnderlyingToken(address token) external onlyOwner;
```

Sets the public stablecoin backing this confidential token. Reverts on the zero address (`"Morphex: zero token"`). Emits `UnderlyingTokenUpdated`.

### setRelayer

```solidity
/// @notice Rotates the relayer signer/role used for confidential mint authorization.
function setRelayer(address newRelayer) external onlyOwner;
```

Rotates `RELAYER_ROLE` to a new signer. Revokes the previous relayer, grants the role to `newRelayer`, and updates `relayer`. Reverts on the zero address (`"Morphex: zero relayer"`). Emits `RelayerUpdated`.

## Minting

### mint

```solidity
/// @notice Mints a confidential amount. Even issuance is encrypted on-chain.
function mint(
    address to,
    externalEuint64 encryptedAmount,
    bytes calldata inputProof
) external onlyOwner returns (euint64);
```

Owner-only mint with an encrypted amount. Lifts `encryptedAmount` with `FHE.fromExternal`, calls the underlying ERC-7984 `_mint`, and returns the ciphertext handle for the transferred amount. Emits `Mint(to)`.

<ParamField path="to" type="address">
  Recipient of the confidential mint.
</ParamField>

<ParamField path="encryptedAmount" type="externalEuint64">
  Encrypted amount as returned by the client SDK.
</ParamField>

<ParamField path="inputProof" type="bytes">
  Zero-knowledge input proof that binds the ciphertext to `(contract, sender)`.
</ParamField>

### relayerMint

```solidity
/// @notice Callable only by the relayer. Users trust the relayer to process the deposit honestly and promptly, or fall back to the escape hatch after the configured delay.
function relayerMint(
    address to,
    externalEuint64 encryptedAmount,
    bytes calldata inputProof
) external onlyRole(RELAYER_ROLE) returns (euint64);
```

Same mechanics as `mint`, gated by `RELAYER_ROLE`. Used by the off-chain relayer after a public deposit into `RelayerVault` is confirmed. Emits `Mint(to)`.

<Note>
  Users trust the relayer to process deposits honestly and promptly, or fall back to the vault's escape hatch after `ESCAPE_HATCH_DELAY`.
</Note>

## Burning and withdrawal

### relayerBurnRequest

```solidity
/// @notice Burns a caller's confidential balance and registers a public withdrawal request with the relayer vault.
function relayerBurnRequest(
    externalEuint64 encryptedAmount,
    bytes calldata inputProof,
    uint256 publicAmount
) external returns (uint256 requestId);
```

Burns the caller's confidential balance and registers a public withdrawal in `RelayerVault`. Requires:

- `relayerVault != address(0)` (`"Morphex: no vault"`)
- `underlyingToken != address(0)` (`"Morphex: no underlying token"`)
- `publicAmount > 0` (`"Morphex: zero amount"`)

Emits `BurnRequested(msg.sender, requestId, publicAmount)`.

The `publicAmount` argument is the plaintext amount the vault will pay out. The relayer reconciles it against the encrypted burn off-chain.

### relayerBurnRequestTo

```solidity
/// @notice Burns a caller's confidential balance and registers a public withdrawal to a different recipient.
function relayerBurnRequestTo(
    address recipient,
    externalEuint64 encryptedAmount,
    bytes calldata inputProof,
    uint256 publicAmount
) external returns (uint256 requestId);
```

Same as `relayerBurnRequest`, but the public payout goes to `recipient` instead of the caller. Adds a `recipient != address(0)` check (`"Morphex: zero recipient"`). Emits `BurnRequestedTo(msg.sender, recipient, requestId, publicAmount)`.

## Interface support

```solidity
function supportsInterface(bytes4 interfaceId)
    public view virtual override(AccessControl, ERC7984) returns (bool);
```

Overrides both parents so both `AccessControl` and `ERC7984` interface IDs return true.

## Events

```solidity
event Mint(address indexed to);
event RelayerVaultUpdated(address indexed vault);
event RelayerUpdated(address indexed relayer);
event UnderlyingTokenUpdated(address indexed token);
event BurnRequested(address indexed user, uint256 indexed requestId, uint256 amount);
event BurnRequestedTo(address indexed user, address indexed recipient, uint256 indexed requestId, uint256 amount);
```

Amounts are deliberately omitted from `Mint`. The underlying ERC-7984 transfer event carries an encrypted handle, and only ACL-authorized parties can decrypt it. `BurnRequested` and `BurnRequestedTo` do include the public payout amount because the vault settlement is inherently public.

<Note>
  MorphexToken is unaudited and intended for testnet use only.
</Note>
